API-PF

Entrada pela API da Polícia Federal

Endpoint OpenID Connect que valida login e senha do usuário e devolve um access token JWT. Login, nome e e-mail saem das claims desse token — nenhuma senha da PF é guardada neste servidor. A configuração é gravada no .env deste servidor e vale no login seguinte, sem reiniciar nada.

Sem a URL do endpoint, a aba API-PF aparece desabilitada na tela de login e todo mundo entra só pelo PolícIA.

Esta página é só para administradores.
